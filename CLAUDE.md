# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Purpose

`otctl` is a Rust CLI wrapping the [OpenThread Border Router (OTBR) REST API](https://openthread.io/reference/border-router/rest-api) v0.3.0. The Rust client is generated by `progenitor` from a vendored OpenAPI spec.

## Repository Structure

- `openapi/ot-rest.yaml` — vendored OpenAPI spec (see `docs/spec-sync.md` for provenance and local patches; never hand-edit without reading that first)
- `src/generated.rs` — `progenitor`-generated client from the spec (do not edit by hand)
- `src/facade.rs` — hand-written wrapper around the generated client; add new command logic here
- `src/cli/` — `clap` subcommand definitions (`node`, `dataset`, `commissioner`, `devices`, `diagnostics`, `actions`)
- `src/render.rs` — table/JSON output formatting
- `src/bin/otctl.rs` — binary entry point
- `tests/` — integration tests using `httpmock` against a mocked OTBR API

## Building and Testing

```bash
cargo build
cargo test
```

## Updating the OpenAPI spec

See `docs/spec-sync.md` for the re-sync procedure and the list of local patches that must be re-applied after pulling a new upstream spec.
